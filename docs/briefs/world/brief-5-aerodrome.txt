RULES, each learned from a pass that went wrong:
- The file headers are the specification: keep them and update them with what you did.
- No GLSL uniform starting with `at` (injected by installFog into your materials); yours start with `ap`.
- Materials and geometries are never cached module-wide; textures may be, keyed by the runway's length/width/surface.
- Name every material ('aerodrome/runway', 'aerodrome/hangar' ...); onBeforeCompile materials carry a versioned customProgramCacheKey.
- No Math.random(): makeRng/noise2/fbm2 from ../config.js, seeded from the runway's numbers as runwaySurface does today.
- Keep every exported name and return shape: runwayMaterial, buildShoulders, buildBuildings -> { objects, obstacles, towerPos } (towerPos stays at the top of the tower - the tower camera sits there), buildBushCamp -> { objects, obstacles }, buildWindsock -> { group, sock } (sock points down -Z at rest), buildMarkers, buildPapiBoxes; LightSet with add/setColor/setPos/finish, getDisc; every PALETTE key that exists now.
